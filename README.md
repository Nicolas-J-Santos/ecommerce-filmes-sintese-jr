## Sobre o Projeto

A Simon FIlmes é uma aplicação web full-stack que oferece uma experiência de compra de filmes. O front-end, desenvolvido com **React** e **Vite**, proporciona uma interface de usuário dinâmica e responsiva, enquanto o back-end, construído com **Node.js**, garante a eficiência das operações. O banco de dados **MongoDB** foi escolhido para armazenar e gerenciar as informações dos produtos. Além disso, o núcleo de criação trabalhou desde a concepção da identidade visual até o design da interface e da experiência do usuário (UI/UX) utilizando o **Figma**, que permitiu a criação de wireframes, protótipos e o design do projeto, garantindo o fluxo de trabalho entre o design e o desenvolvimento.

## ✨ Funcionalidades

- **Visualização de Produtos:** Exibição do catálogo ordenado pela popularidade com imagens e informações pertinentes.
- **Busca e Filtragem:** Ferramenta de busca de dados específicos por filtros qualitativos e quantitativos.
- **Carrinho de Compras:** Mecanismos para remover itens, visualizar o subtotal e para finalizar a compra.

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido com as seguintes tecnologias:

**Front-End:**

- **[React](https://reactjs.org/):** Biblioteca JavaScript para a construção de interfaces de usuário.
- **[Vite](https://vitejs.dev/):** Ferramenta de build que oferece uma experiência de desenvolvimento prática.
- **[JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript):** Linguagem de programação para a lógica da aplicação.
- **[CSS](https://developer.mozilla.org/pt-BR/docs/Web/CSS):** Estilização para criar o layout funcional e aplicado.
- **[Axios](https://axios-http.com/):** Cliente HTTP para realizar requisições à API.

**Back-End:**

- **[Node.js](https://nodejs.org/):** Ambiente de execução JavaScript no servidor.
- **[Express](https://expressjs.com/):** Framework web para Node.js.
- **[MongoDB](https://www.mongodb.com/):** Banco de dados NoSQL orientado a documentos.
- **[Postman](https://www.postman.com/):** Plataforma para construção e uso de API's.

**Criação:**

- **[Figma](https://www.figma.com/):** Ferramenta de design para a interface e experiência do usuário.
